## 🌌 Sobre o Projeto

Este portfólio foi desenvolvido do zero para refletir não apenas as minhas habilidades técnicas, mas também a minha identidade como desenvolvedor. Abandonando os templates genéricos, criei uma experiência "Dark Cyberpunk" minimalista que comunica diretamente com recrutadores tech e engenheiros.

O foco da arquitetura do site é a **performance**, **semântica** e **internacionalização**.

### ✨ Principais Features

- **Estética Terminal/Matrix:** Animações Typewriter (`JS Vanilla`) e background interativo em 3D utilizando `Three.js` para renderizar uma "chuva digital" e malhas cibernéticas.
- **Internacionalização Dinâmica (i18n):** Suporte nativo a Português (PT-BR), Inglês (EN) e Espanhol (ES) sem recarregamento da página, utilizando um motor customizado via atributos `data-lang-*`.
- **Arquitetura CSS Moderna:** Construído com CSS Puro utilizando CSS Variables, Grid Layout, Flexbox e Glassmorphism (`backdrop-filter`), garantindo zero dependências pesadas como Bootstrap ou Tailwind.
- **Fully Responsive:** Layout fluido que se adapta desde monitores ultrawide até telas de smartphones, com menu mobile interativo (`fullscreen overlay`).
- **SEO & Acessibilidade (a11y):** Tags HTML5 semânticas, atributos ARIA para leitores de tela e suporte a preferência de sistema para animações (`prefers-reduced-motion`).

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído **sem frameworks de UI**, provando o domínio sobre a tríade fundamental da web:

* **HTML5:** Marcação semântica profunda e estruturação de dados para SEO.
* **CSS3 Vanilla:** Animações chave (`@keyframes`), propriedades customizadas (variáveis globais), layout fluido e design responsivo.
* **JavaScript (ES6+):** Lógica de internacionalização, motor de digitação sequencial (Typewriter) e manipulação eficiente do DOM.
* **Three.js:** Utilizado exclusivamente na hero section para o background imersivo em WebGL.

## 🚀 Como Executar Localmente

Como o projeto é totalmente estático e não requer build steps (Node.js/NPM), você pode rodá-lo de forma extremamente simples:

1. Clone este repositório:
   ```bash
   git clone https://github.com/NandinAugusto/portfolio.git
   ```
2. Acesse o diretório:
   ```bash
   cd portfolio
   ```
3. Abra o arquivo `index.html` diretamente no seu navegador, ou utilize uma extensão como o **Live Server** no VS Code para auto-reload.
